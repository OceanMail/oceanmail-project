# Public-source maintenance workstream

All five active repositories are public, licensed and protected. Project provides
the documentation spine; Station and Desktop contain experimental implementations;
Server and Infrastructure are bootstraps. See [PUBLICATION.md](../PUBLICATION.md).

## Continuing work

- Keep contributor documentation self-contained and link only to accessible public resources.
- Validate changed document links and JSON, and check CI on the actual proposed commit.
- Preserve neutral contributor identities, third-party notices and source provenance.
- Keep secrets, personal data and operational inventories out of source, logs and attachments.
- Maintain runner isolation, read-only PR tokens and protected main.
- Complete and record the external-fork acceptance test; it remains unverified.

Public source is not production readiness, binary redistribution approval or radio
authorization. Follow [public collaboration](../docs/specifications/public-collaboration.md)
and the [release checklist](../docs/specifications/publication-readiness.md).
