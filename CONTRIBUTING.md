# Contributing to OceanMail

Source and documentation licenses are published in [LICENSING.md](LICENSING.md).
Fork this public repository, create a topic branch and submit a pull request
against `main`. Maintainers review and merge; upstream write access is unnecessary.
No DCO or additional inbound agreement is adopted.

Maintainers review and merge; public review/comment access grants no merge or
architecture authority. Normal integration preserves a merge commit.

Read README.md, AGENTS.md and the relevant workstream/specification before editing.
This repository contains documentation, not the component applications. Keep
implementation changes in their owning repositories and link cross-repository work.
Explain the problem, change, exact evidence and remaining limitations in the PR.
Check relative Markdown links and JSON syntax locally. No application build is
required for this documentation repository. Do not label static checks as live,
radio or production validation.

Keep changes focused. Preserve third-party notices and identify copied/adapted
source, revision, license and changes. Disclose material AI assistance and verify
its output; contributors remain responsible for correctness and provenance.
Do not upload private messages, credentials, personal test locations, operational
data or unredacted logs. See SECURITY.md for sensitive findings.

Public PR checks must use GitHub-hosted runners without repository secrets.
Never request access to a maintainer workstation or trusted runner for PR code.
Be respectful and keep discussion relevant; maintainers may close unsuitable work.
No response-time, release, support or contribution-acceptance guarantee is made.

The publication decisions are in
[publication-decisions.md](docs/specifications/publication-decisions.md). No additional contribution agreement is required by that document.
