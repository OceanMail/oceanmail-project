# Public documentation privacy — 2026-09-26

All five active repositories publish source. Public documentation must be
self-contained: use the public repository inventory, current contracts and public
issues/PRs rather than requiring unavailable background material.

Keep personal names/contact details, workstation paths, live credentials, private
mail, test-site details and operational inventories out of published material.
Use neutral author and committer identities with a GitHub noreply address for
maintainer-generated commits, while preserving required third-party attribution.

Documentation cleanup is a current-tree change. It does not rewrite Git history,
erase prior public copies or certify production/RF safety. See
[publication status](../../PUBLICATION.md) and [SECURITY.md](../../SECURITY.md).
