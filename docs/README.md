# Project Documentation Index

This directory holds organization-level architecture, major decisions, specifications/process rules, terminology, interfaces, research/deferred work, and history.

- `architecture/` — current system shape.
- `decisions/` — major ADR-style decisions and supersession links.
- `interfaces/` — cross-component boundaries/contracts at organization level.
- `specifications/` — durable project/process specifications that are not component implementation details.
- `research/` — current prior-art research and deferred/wishlist material; not implementation authority unless promoted elsewhere.
- `terminology/` — authoritative shared vocabulary.
- `history/` — historical transitions and rationale summaries; not current-state authority.

Component implementation details remain in the owning repository.
